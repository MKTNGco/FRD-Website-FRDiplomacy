# FRD Website — frdiplomacy.org content archive

Rebuild context for the **Foundation for Religious Diplomacy** website (https://www.frdiplomacy.org/). Use this repo to give Claude (or any agent) the current site's copy, structure, and assets when planning the rebuild.

**Not a live site. Not for hosting.** This is a Squarespace scrape captured around **Oct 13, 2026**.

## Where to look
- `inventory/README.md` — how the capture was done, plus sitemap, redirects, assets, and issue logs
- `content/pages`, `content/posts` — normalized markdown of every page and blog post (original copy)
- `raw/` — original HTML, Squarespace JSON, Firecrawl markdown, and sitemap.xml
- `assets/` — downloaded images and PDFs
- `scripts/archive_site.py` — the capture script
